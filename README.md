# Lab 1 – Semantic HTML Page

**Course:** INFO 253A, Front-End Web Architecture /
**Author:** Jiwon (Dinah) Lee

## About

A single-page website (`lab1.html`) built using only semantic HTML5 elements, no `<div>` tags anywhere.

## Structure

- `<header>` — site title and `<nav>` with links to each section
- `<main>` — three sections: About, Projects, Contact
  - About includes a `<figure>` with an image and caption
  - Projects lists work using `<article>` elements
  - Contact includes an `<address>` with an email link
- `<footer>` — closing/copyright line

## Rules followed

- Page is divided into `<header>`, `<main>`, and `<footer>`
- `<nav>` in the header includes at least one link
- `<main>` contains at least three `<section>` elements
- Includes at least one media element (image) and one contact element (email)
- No `<div>` elements used, semantic tags only
